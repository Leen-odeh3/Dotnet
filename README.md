## What is Connection Pooling?
Connection Pooling is a technique used to reuse existing database connections instead of opening and closing a new one for each request.
It improves performance and resource management by reducing the overhead of creating new connections.

#### 🚀 Why Use Connection Pooling?
✅ Improves Performance: Reduces the time and cost of creating new connections.

✅ Efficient Resource Use: Minimizes the number of open connections, reducing server load.

✅ Scalable: Handles high traffic more effectively.
